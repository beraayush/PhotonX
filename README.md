# PhotonX Pro v3.0 (Vivo T3x Computational Camera)

## Quick Upload to GitHub & APK Build
1. Extract this ZIP archive completely (including the hidden `.github/workflows/build_apk.yml` folder).
2. Upload all extracted files and folders to the root of your `PhotonX` GitHub repository on the `main` branch.
3. Open the **Actions** tab in GitHub, wait for **Build PhotonX APK** to turn green, and download **`PhotonX-VivoT3x-APK`** under **Artifacts**.
4. Extract `app-debug.apk` on your Vivo T3x and install it. Open **Settings** inside the app to confirm **`v3.0.0-PhotonX-Pro (#3)`**.
